# g-udi .github

This repository contains organization-level GitHub files for `g-udi`.

- `profile/README.md` powers the public organization profile at https://github.com/g-udi.
- `CONTRIBUTING.md` is the default contribution guide for public repositories that do not define their own.
- `SECURITY.md` is the default security policy for the same repositories.

Keep this repository focused on shared community, security and profile documentation.
